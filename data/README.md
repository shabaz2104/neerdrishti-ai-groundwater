# Data Handling Rules

## Raw data

Files in `data/raw/` are original source datasets. They must not be manually modified.

## Processed data

Files in `data/processed/` are generated from raw data through documented processing steps.

## Source of truth

The original source dataset remains the authoritative input.

## Current dataset status

The actual Maharashtra groundwater dataset has not yet been added to the repository.

## Expected scope

The expected initial scope is:

- Maharashtra
- block-level groundwater data
- 2015–2024
- CSV-compatible source data

These are requirements from the SRS, not assumptions about the actual dataset.
